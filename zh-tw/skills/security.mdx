## API Key

- 僅透過 `NEWAPI_API_KEY` 環境變數提供。
- 不要寫入儲存庫、JSON 請求檔、Skill 檔案或 Agent 回覆。
- 懷疑外洩時立即撤銷並重新生成。

## 媒體內容

- 優先使用可存取的 HTTPS 媒體連結。
- 不要在日誌中列印完整 base64、二進位資料或過長的 Data URL。
- 僅提交有權處理的圖片、音訊和影片素材。

## 任務與費用

- Agent 提交前應確認模型、數量、時長和解析度。
- 長任務應保存任務 ID，並透過查詢介面取得狀態。
- 單次查詢失敗不代表生成任務已經失敗。

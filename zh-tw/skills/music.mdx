---
title: "NewAPI Music"
description: "Create music generation tasks and query their results by task ID with NewAPI."
---

`newapi-music` 預設呼叫 `https://api.aiid.edu.kg`，並從 `NEWAPI_API_KEY` 讀取驗證資訊。

## 支援的命令

| 命令 | API | 用途 |
| --- | --- | --- |
| `models` | `GET /v1/models` | 查詢可用模型 |
| `create` | `POST /suno/submit/music` | 建立音樂任務 |
| `status` | `GET /suno/fetch/{task_id}` | 依 ID 查詢音樂任務 |

## 呼叫範例

```bash
node scripts/newapi-music.mjs models
node scripts/newapi-music.mjs create --json music-request.json
node scripts/newapi-music.mjs status --id task_xxx
```

建立任務後，保存回傳的任務 ID，再使用對應的查詢命令取得狀態。長任務不要維持單次 HTTP 請求等待。

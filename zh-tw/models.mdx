### Gemini Omni

`gemini-omni` 使用 new-api 對外公開模型名，可透過 `/v1/videos` 或 `/api/v3/contents/generations/tasks` 呼叫；使用 `mode=t2v/r2v/edit` 區分文生、參考生成和影片編輯，時長會自動匹配到 4 / 6 / 8 / 10 秒檔。



| 模型 | 主要接入方式 |

|---|---|

| `gemini-omni` | `/v1/videos` / `/api/v3/contents/generations/tasks` |

### Kling Videos

Kling 4.0 直接支援標準 OpenAI/Sora prompt/seconds/size/input_reference，以及 Seedance content/duration/resolution/ratio/mode，無需額外的 contents/settings/options。舊信封仍持續相容。mode=t2v/i2v/i2v_first_last/reference_images/reference_material 用於區分情境；有參考素材時預設為 reference_material，無素材時預設為 t2v。



| 模型 | 主要接入方式 |

|---|---|

| `kling-4.0` | `/api/v3/contents/generations/tasks` / `/v1/videos` / `/text-to-video/kling-4.0` / `/image-to-video/kling-4.0` / `/omni-video/kling-4.0` |

| `kling-4.0-1080p` | `/api/v3/contents/generations/tasks` / `/v1/videos` / `/text-to-video/kling-4.0` / `/image-to-video/kling-4.0` / `/omni-video/kling-4.0` |

| `kling-video` | `/api/v3/contents/generations/tasks` / `/v1/videos` |

| `kling-*` | `/api/v3/contents/generations/tasks` / `/v1/videos` |



### MiniMax / Hailuo

使用統一影片能力接入。`minimax-h3` 支援文生影片、圖片參考和音訊參考；`hailuo-2.3` 需要首幀圖片，適合首幀圖生影片。



| 模型 | 主要接入方式 |

|---|---|

| `minimax-h3` | `/v1/videos` / `/api/v3/contents/generations/tasks` |

| `hailuo-2.3` | `/v1/videos` / `/api/v3/contents/generations/tasks` |

| `hailuo*` | `/v1/videos` / `/api/v3/contents/generations/tasks` |



### Vidu

Vidu Q4：`vidu-q4` 固定為 720p，`vidu-q4-540p` 固定為 540p，支援生成 3～16 秒影片。至少需要 1 張圖片，最多支援 15 張參考圖；參考生成可附帶最多 3 段 MP3 音訊，每段 3～12 秒、最大 50MB。不支援純文字生成、指定首尾幀或參考影片。多張圖片用於共同參考，不代表首尾位置。可透過 `POST /v1/videos`、`POST /api/v3/contents/generations/tasks`，或 Vidu 格式 `POST /ent/v2/img2video`、`POST /ent/v2/reference2video` 建立任務。統一入口建議使用 `mode=reference_images`；附帶音訊時使用 `mode=reference_material`。參考音訊可使用 `audio_urls`，Seedance 格式也可使用標準 `content` 的 `audio_url` 項；`audio` 布林欄位表示生成音訊開關，與參考音訊 URL 清單分別使用。解析度須與模型名稱一致。舊版 Q3/Q2/V2 模型請繼續依各自能力使用原有介面。



| 模型 | 主要接入方式 |

|---|---|

| `vidu-q4` | `/ent/v2/...` / `/v1/videos` |

| `vidu-q4-540p` | `/ent/v2/...` / `/v1/videos` |

| `viduq3-turbo` | `/ent/v2/...` / `/v1/videos` |

| `viduq2` | `/ent/v2/...` / `/v1/videos` |

| `vidu2.0` | `/ent/v2/...` / `/v1/videos` |

| `vidu*` | `/ent/v2/...` / `/v1/videos` |

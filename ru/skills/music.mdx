---
title: "NewAPI Music"
description: "Create music generation tasks and query their results by task ID with NewAPI."
---

`newapi-music` по умолчанию вызывает `https://api.aiid.edu.kg` и читает данные аутентификации из `NEWAPI_API_KEY`.

## Поддерживаемые команды

| Команда | API | Назначение |
| --- | --- | --- |
| `models` | `GET /v1/models` | Запрос доступных моделей |
| `create` | `POST /suno/submit/music` | Создать музыкальную задачу |
| `status` | `GET /suno/fetch/{task_id}` | Получить музыкальную задачу по ID |

## Пример вызова

```bash
node scripts/newapi-music.mjs models
node scripts/newapi-music.mjs create --json music-request.json
node scripts/newapi-music.mjs status --id task_xxx
```

После создания задачи сохраните возвращённый ID задачи, затем используйте соответствующую команду запроса, чтобы получить статус. Для длительных задач не оставляйте один запрос HTTP в ожидании.

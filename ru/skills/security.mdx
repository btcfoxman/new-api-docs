## API Key

- Предоставляется только через переменную окружения `NEWAPI_API_KEY`.
- Не записывайте в репозиторий, JSON-файлы запросов, файлы Skill или ответы Agent.
- При подозрении на утечку немедленно отзовите и сгенерируйте заново.

## Медиа-контент

- Предпочитайте доступные медиассылки HTTPS.
- Не выводите в логи полный base64, двоичные данные или слишком длинные Data URL.
- Отправляйте только изображения, аудио и видео, на обработку которых у вас есть права.

## Задачи и стоимость

- Перед отправкой Agent следует подтвердить модель, количество, длительность и разрешение.
- Для долгих задач следует сохранять ID задачи и получать статус через интерфейс запроса.
- Одна неудачная попытка запроса не означает, что задача генерации уже завершилась с ошибкой.

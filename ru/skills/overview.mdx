NewAPI Skills предоставляют стабильный рабочий процесс генерации медиа для таких агентов, как Codex, Claude Code и других.

## Доступные Skills

| Skill | Возможности |
| --- | --- |
| `newapi-image` | Генерация изображений, редактирование изображений, асинхронный запрос задач изображений |
| `newapi-video` | Sora и Seedance: создание видеозадач, запрос и получение результатов |
| `newapi-music` | Создание музыкальных задач и запрос по ID |

## Установка

```bash
npx skills add https://docs.aiid.edu.kg
```

После установки настройте `NEWAPI_API_KEY`, затем выполняйте задачи согласно инструкции для соответствующего Skill.

## Принцип работы

- Во время выполнения модель выполняет запросы через `/v1/models`.
- Для видео, музыки и асинхронных задач изображений создание и запрос разделены.
- Сложные запросы передаются через JSON-файл.
- Skills не выводит API Key, полный base64 или бинарные данные медиа.

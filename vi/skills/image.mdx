---
title: "NewAPI Image"
description: "Generate and edit images with NewAPI, including asynchronous Responses API image tasks."
---

`newapi-image` mặc định gọi `https://api.aiid.edu.kg` và đọc thông tin xác thực từ `NEWAPI_API_KEY`.

## Các lệnh được hỗ trợ

| Lệnh | API | Mục đích |
| --- | --- | --- |
| `models` | `GET /v1/models` | Truy vấn các model khả dụng |
| `generate` | `POST /v1/images/generations` | Tạo ảnh |
| `edit` | `POST /v1/images/edits` | Chỉnh sửa ảnh |
| `responses-create` | `POST /v1/responses` | Tạo tác vụ ảnh bất đồng bộ |
| `responses-get` | `GET /v1/responses/{response_id}` | Truy vấn tác vụ ảnh bất đồng bộ |

## Ví dụ gọi

```bash
node scripts/newapi-image.mjs models
node scripts/newapi-image.mjs generate --json image-request.json
node scripts/newapi-image.mjs edit --json edit-request.json
node scripts/newapi-image.mjs responses-create --json responses-request.json
node scripts/newapi-image.mjs responses-get --id resp_xxx
```

Sau khi tạo tác vụ, hãy lưu ID tác vụ được trả về, rồi dùng lệnh truy vấn tương ứng để lấy trạng thái. Với tác vụ dài, đừng giữ một yêu cầu HTTP duy nhất để chờ.

NowAPI Skills cung cấp quy trình tạo media ổn định cho các Agent như Codex, Claude Code.

## Skills khả dụng

| Skill | Năng lực |
| --- | --- |
| `nowapi-image` | Tạo ảnh, chỉnh sửa ảnh, truy vấn tác vụ ảnh bất đồng bộ |
| `nowapi-video` | Tạo, truy vấn và lấy kết quả tác vụ video Sora và Seedance |
| `nowapi-music` | Tạo tác vụ âm nhạc và truy vấn theo ID |

## Cài đặt

```bash
npx skills add https://docs.aiid.edu.kg
```

Sau khi cài đặt xong, cấu hình `NOWAPI_API_KEY`, rồi thực hiện tác vụ theo hướng dẫn của Skill tương ứng.

## Cách hoạt động

- Mô hình truy vấn thông qua `/v1/models` trong thời gian chạy.
- Tác vụ video, âm nhạc và ảnh bất đồng bộ áp dụng cách tách riêng giữa tạo và truy vấn.
- Yêu cầu phức tạp được truyền vào qua tệp JSON.
- Skills sẽ không xuất API Key, base64 đầy đủ hoặc nội dung nhị phân của media.

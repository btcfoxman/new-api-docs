---
title: "Installation rapide"
description: "Installez NowAPI Skills, configurez API Key et vérifiez que l’Agent peut accéder à NowAPI."
---

## Prérequis système

- Node.js 18 ou version ultérieure
- Une clé NowAPI API valide
- Un outil prenant en charge Agent Skills

## Installer les Skills

```bash
npx skills add https://docs.aiid.edu.kg
```

## Configurer les variables d’environnement

```bash
export NOWAPI_BASE_URL="https://api.aiid.edu.kg"
export NOWAPI_API_KEY="YOUR_API_KEY"
```

PowerShell：

```powershell
$env:NOWAPI_BASE_URL="https://api.aiid.edu.kg"
$env:NOWAPI_API_KEY="YOUR_API_KEY"
```

N’inscrivez pas la vraie clé API dans le dépôt, les fichiers Skill ou les réponses de chat. Une fois la configuration terminée, demandez à l’Agent d’exécuter la commande `models` de n’importe quel Skill pour vérifier.

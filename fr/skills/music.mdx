---
title: "NowAPI Music"
description: "Create music generation tasks and query their results by task ID with NowAPI."
---

`nowapi-music` appelle par défaut `https://api.aiid.edu.kg` et lit les informations d’authentification depuis `NOWAPI_API_KEY`.

## Commandes prises en charge

| Commande | API | Utilisation |
| --- | --- | --- |
| `models` | `GET /v1/models` | Interroger les modèles disponibles |
| `create` | `POST /suno/submit/music` | Créer une tâche musicale |
| `status` | `GET /suno/fetch/{task_id}` | Interroger une tâche musicale par ID |

## Exemples d’appel

```bash
node scripts/nowapi-music.mjs models
node scripts/nowapi-music.mjs create --json music-request.json
node scripts/nowapi-music.mjs status --id task_xxx
```

Après avoir créé la tâche, enregistrez l’ID de tâche renvoyé, puis utilisez la commande de requête correspondante pour obtenir l’état. Pour les tâches longues, n’attendez pas en gardant une seule requête HTTP.

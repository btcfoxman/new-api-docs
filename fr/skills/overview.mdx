NowAPI Skills fournit à des agents comme Codex et Claude Code un workflow stable de génération de médias.

## Skills disponibles

| Skill | Capacités |
| --- | --- |
| `nowapi-image` | Génération d’images, édition d’images, consultation asynchrone des tâches d’images |
| `nowapi-video` | Création, consultation et récupération des résultats des tâches vidéo Sora et Seedance |
| `nowapi-music` | Création de tâches musicales et consultation par ID |

## Installation

```bash
npx skills add https://docs.aiid.edu.kg
```

Après l’installation, configurez `NOWAPI_API_KEY`, puis exécutez les tâches selon les instructions du Skill correspondant.

## Fonctionnement

- Le modèle effectue des requêtes via `/v1/models` au moment de l’exécution.
- Les tâches vidéo, musicales et asynchrones d’images utilisent une séparation entre création et consultation.
- Les requêtes complexes sont transmises via des fichiers JSON.
- Les Skills n’exposent pas la clé API, le base64 complet ni le contenu binaire des médias.

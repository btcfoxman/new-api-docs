---
title: "NowAPI Image"
description: "Generate and edit images with NowAPI, including asynchronous Responses API image tasks."
---

`nowapi-image` appelle par défaut `https://api.aiid.edu.kg` et lit les informations d’authentification depuis `NOWAPI_API_KEY`.

## Commandes prises en charge

| Commande | API | Utilisation |
| --- | --- | --- |
| `models` | `GET /v1/models` | Interroger les modèles disponibles |
| `generate` | `POST /v1/images/generations` | Générer des images |
| `edit` | `POST /v1/images/edits` | Modifier des images |
| `responses-create` | `POST /v1/responses` | Créer une tâche d’image asynchrone |
| `responses-get` | `GET /v1/responses/{response_id}` | Interroger une tâche d’image asynchrone |

## Exemples d’appel

```bash
node scripts/nowapi-image.mjs models
node scripts/nowapi-image.mjs generate --json image-request.json
node scripts/nowapi-image.mjs edit --json edit-request.json
node scripts/nowapi-image.mjs responses-create --json responses-request.json
node scripts/nowapi-image.mjs responses-get --id resp_xxx
```

Après avoir créé la tâche, enregistrez l’ID de tâche renvoyé, puis utilisez la commande de requête correspondante pour obtenir l’état. Pour les tâches longues, n’attendez pas en gardant une seule requête HTTP.

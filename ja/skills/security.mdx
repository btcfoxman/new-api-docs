## API Key

- `NEWAPI_API_KEY` 環境変数のみを通じて提供します。
- リポジトリ、JSON リクエストファイル、Skill ファイル、または Agent の返信に書き込まないでください。
- 漏えいが疑われる場合は、直ちに失効させて再生成してください。

## メディアコンテンツ

- アクセス可能な HTTPS メディアリンクを優先して使用します。
- ログに完全な base64、バイナリデータ、または非常に長い Data URL を出力しないでください。
- 処理権限のある画像、音声、動画素材のみを送信してください。

## タスクと料金

- Agent は送信前に、モデル、数量、長さ、解像度を確認する必要があります。
- 長時間タスクではタスク ID を保存し、照会 API で状態を取得してください。
- 1 回の照会失敗は、生成タスクの失敗を意味しません。

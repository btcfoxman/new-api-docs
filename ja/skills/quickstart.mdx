title: "クイックインストール"

---

## 環境要件

- Node.js 18 以降
- 有効な NewAPI API Key
- Agent Skills をサポートするツール

## Skills のインストール

```bash
npx skills add https://docs.aiid.edu.kg
```

## 環境変数の設定

```bash
export NEWAPI_BASE_URL="https://api.aiid.edu.kg"
export NEWAPI_API_KEY="YOUR_API_KEY"
```

PowerShell：

```powershell
$env:NEWAPI_BASE_URL="https://api.aiid.edu.kg"
$env:NEWAPI_API_KEY="YOUR_API_KEY"
```

本物の API Key をリポジトリ、Skill ファイル、またはチャット返信に書き込まないでください。設定後、Agent に任意の Skill の `models` コマンドを実行させて検証してください。

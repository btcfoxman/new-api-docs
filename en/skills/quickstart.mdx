---
title: "Quick Install"
description: "Install NewAPI Skills, configure the API Key, and verify that the Agent can access NewAPI."
---

## Environment Requirements

- Node.js 18 or later
- A valid NewAPI API Key
- A tool that supports Agent Skills

## Install Skills

```bash
npx skills add https://docs.aiid.edu.kg
```

## Configure Environment Variables

```bash
export NEWAPI_BASE_URL="https://api.aiid.edu.kg"
export NEWAPI_API_KEY="YOUR_API_KEY"
```

PowerShell：

```powershell
$env:NEWAPI_BASE_URL="https://api.aiid.edu.kg"
$env:NEWAPI_API_KEY="YOUR_API_KEY"
```

Do not write a real API Key into the repository, Skill files, or chat replies. After configuration, have the Agent run any Skill's `models` command to verify.

---
title: "NewAPI Video"
description: "Create and query Sora-compatible and Seedance-compatible video generation tasks with NewAPI."
---

`newapi-video` uses `https://api.aiid.edu.kg` by default and reads authentication information from `NEWAPI_API_KEY`.

## Supported Commands

| Command | API | Purpose |
| --- | --- | --- |
| `models` | `GET /v1/models` | List available models |
| `sora-create` | `POST /v1/videos` | Create Sora compatible video task |
| `sora-status` | `GET /v1/videos/{task_id}` | Query Sora compatible video task |
| `sora-content` | `GET /v1/videos/{task_id}/content` | Download video results |
| `seedance-create` | `POST /api/v3/contents/generations/tasks` | Create Seedance video task |
| `seedance-status` | `GET /api/v3/contents/generations/tasks/{task_id}` | Query Seedance video task |

## Usage Examples

```bash
node scripts/newapi-video.mjs models
node scripts/newapi-video.mjs sora-create --json video-request.json
node scripts/newapi-video.mjs sora-status --id video_xxx
node scripts/newapi-video.mjs seedance-create --json seedance-request.json
node scripts/newapi-video.mjs seedance-status --id task_xxx
```

After creating a task, save the returned task ID, then use the corresponding query command to get its status. For long-running tasks, do not keep a single HTTP request waiting.
